# IN6227 Assignment 1 (Variant 1)

Logistic Regression vs Decision Tree (scikit-learn). Random seed: 42.

## Requirements

```bash
pip install pandas numpy scikit-learn matplotlib joblib
```

## Run

Put the course-provided `train.csv` and `test.csv` in one folder, then:

```bash
python train.py --data-dir path/to/dataset
python check_coursework.py --data-dir path/to/dataset   # run after train.py
```

Results are written to `outputs/` (default `--output-dir`).
